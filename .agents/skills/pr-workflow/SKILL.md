# Pull request workflow

Pull requests support changelog generation, so do not push changes directly to `main`.

1. Create or use a branch and commit the changes on it.
2. Push the branch and open a pull request targeting `main`.
3. Run required checks and, when they pass and the repository permits it, merge the pull request yourself.
