# Planning

1. Inspect the repository and define the intended outcome and verification.
2. Save a Markdown plan under `.agents/plans/` using the next available zero-padded number, such as `000-research.md`; do not renumber existing plans.
3. Divide work into small, actionable phases with checkboxes, including research, implementation where applicable, and validation.
4. Record source links and unresolved decisions when relevant. Keep checkboxes in sync with actual progress and note checks run and remaining risks.
